# AIM: AI Impact and Momentum

AIM (AI Impact and Momentum) is an integrated system for assessing AI
readiness, developing an implementation roadmap, measuring outcomes
through KPIs, and evaluating maturity.

This repository contains the materials designated for the **free public
AIM release**. It is intended to help organisations understand and apply
the published AIM core independently.

## What AIM covers

AIM brings together four connected components:

1. **Readiness Assessment** --- assesses organisational readiness for
AI.
2. **Integrated Implementation Roadmap** --- connects readiness and
priorities to an implementation path.
3. **KPI Framework** --- supports measurement of AI performance and
impact.
4. **Maturity Model** --- provides a staged view of AI capability and
progress.

Refer to the released AIM materials for the definitions, methods and
guidance applicable to each component.
